
# 구현할 기능 목록 정리

## 게임 시작
    1. 게임 시작 문구 출력
    2. 컴퓨터가 1~9까지의 서로 다른 임의의 수 3개를 선택
    3. 플레이어가 1~9까지의 서로 다른 임이의 수 3개를 입력
    4. 플레이어가 잘못된 값을 입력할 경우 IllegalArgumentException 을 발생시켜 앱을 종료

## 게임 진행
    1. 플레이어 숫자와 컴퓨터 숫자에 같은 숫자가 있는지 비교
    2. 같은 숫자가 있으면 자리를 비교
    3. 자리를 비교하여 같은 숫자와 같은 자리면 1스트라이크를 출력
    4. 같은 숫자이지만 다른 자리일 경우 1볼을 출력
    5. 같은 숫자가 없다면 낫싱을 출력

## 게임 종료
    1. 3스트라이크가 출력될 경우 게임 종료 문구를 출력하고 종료
    2. 종료되면 재시작 문구를 출력
